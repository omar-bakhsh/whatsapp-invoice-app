## 🌟 نظرة عامة على المشروع (Overview)

**WhatsApp Invoice Automator** هو نظام محلي عالي الأداء مصمم للشركات، المتاجر، مراكز الصيانة، والمكاتب الخدمية لتسريع وأتمتة عملية إرسال الفواتير للعملاء بنقرة زر واحدة. 

يقوم النظام بتحليل ملفات الفواتير (PDF) سواءً كانت رقمية أو ممسوحة ضوئياً (OCR)، واستخراج رقم جوال العميل واسمه بذكاء ودقة متناهية، ثم إرسال الفاتورة مع رسالة شكر مخصصة ورابط لتقييم المتجر عبر Google Maps، مع تطبيق أعلى معايير الأمان لتفادي حظر رقم الواتساب.

## ✨ المميزات الرئيسية (Core Features)

### 🏢 1. إدارة الفروع المتعددة (Multi-Branch Management)
- التبديل الفوري بين الفروع المختلفة (مثل: الفرع الرئيسي، فرع الرياض، فرع الخبر... إلخ).
- حفظ إعدادات مستقلة وقوالب رسائل مخصصة لكل فرع على حدة.
- إمكانية ربط كل فرع بجلسة واتساب ورقم مستقل.

### 🛡️ 2. درع الحماية الذكي ضد الحظر (Smart Anti-Ban Shield)
- **فواصل زمنية عشوائية (Randomized Jitter Delays):** تأخير زمني طبيعي بين كل رسالة وأخرى (مثلاً: 10 - 20 ثانية قابلة للتخصيص).
- **فترات التبريد والاستراحة (Batch Cooldown Periods):** إيقاف الإرسال تلقائياً لمدة محددة (مثل: 60 ثانية) بعد كل دفعة (مثل 8 فواتير) لمحاكاة السلوك البشري الطبيعي.
- **محاكاة الكتابة الحية (Typing State Emulation):** إرسال إشارة "جاري الكتابة..." (`sendStateTyping`) قبل إرسال الرسالة لإشعار خوادم الواتساب بالتفاعل البشري.
- **الحصص اليومية القصوى (Daily Quota Limits):** وضع حد أقصى للرسائل اليومية للفرع لمنع إغراق الخوادم.
- **القائمة المستبعدة (Blacklist):** استبعاد أرقام الفروع والمشرفين لمنع إرسال الفواتير لهم عن طريق الخطأ.

### 🎲 3. تنويع نصوص الرسائل الذكي (Spintax Engine)
- دعم صيغ الـ Spintax التوليدية مثل `{حياك الله|أهلاً بك|مرحباً بك}` لتوليد رسائل فريدة ومختلفة لكل عميل، مما يمنع تصنيف المحتوى كرسائل دعائية متكررة (Spam).
- تخصيص المتغيرات التلقائية: `{{name}}` (اسم العميل)، `{{link}}` (رابط التقييم)، `{{branch}}` (اسم الفرع).

### 🔍 4. محرك استخراج البيانات المتقدم (Multi-Strategy Extraction)
- مسح شامل لجميع صفحات ملفات الـ PDF وليس الصفحة الأولى فقط.
- دعم كامل للأرقام العربية (٠١٢٣٤٥٦٧٨٩) والمشرقية والإنجليزية، وتطبيع الرموز غير المرئية وعلامات التنسيق المخفية (Unicode Zero-Width & Directional Marks).
- نظام تقييم سياقي (Contextual Scoring) يميز رقم العميل عن الأرقام الضريبية، السجلات التجارية، وأرقام الفروع.
- استخراج احتياطي من اسم ملف الفاتورة في حال كان الاسم يحتوي على الرقم.
- محرك التعرف الضوئي على النصوص (OCR) باستخدام **Tesseract.js** بدقة فائقة للفواتير الممسوحة أو المصورة.

### 📊 5. لوحة تحكم عصرية وسجل تفاعلي (Modern Real-Time UI)
- تصميم زجاجي عصري (Glassmorphism UI) احترافي ومريح للعين مع تناسق لوني فائق.
- أيقونات SVG دقيقة وسريعة التحميل لجميع الأزرار والبطاقات التفاعلية.
- مؤشرات إحصائية مباشرة (إجمالي الفواتير، العمليات الناجحة، المتعثرة، الاستهلاك اليومي).
- معاينة حية لشكل رسالة الواتساب ومرفق الفاتورة مع إمكانية تجربة تنويع النصوص (Spintax Live Reroll).
- تصدير كامل لسجل العمليات إلى ملفات Excel / CSV بضغطة زر.

## 🛠️ التقنيات المستخدمة (Tech Stack)

### **الواجهة الخلفية (Backend & Core Engine):**
- **[Node.js](https://nodejs.org/):** بيئة التشغيل الأساسية.
- **[Express.js](https://expressjs.com/):** خادم الويب ومعالجة الـ REST APIs لرفع الفواتير وإدارة الإعدادات.
- **[WhatsApp-Web.js](https://wwebjs.dev/):** محرك التفاعل مع بروتوكول WhatsApp Web وأتمتة الجلسات.
- **[Puppeteer](https://pptr.dev/):** متصفح Chromium المدمج لتشغيل جلسات الواتساب المستقرة بدون واجهة رأسية (Headless).
- **[Socket.io](https://socket.io/):** بث حالة الاتصال، رمز الاستجابة السريعة (QR Code)، ونسب الإنجاز في الوقت الفعلي.
- **[Multer](https://github.com/expressjs/multer):** معالجة ورفع ملفات الفواتير والوسائط بأمان.

### **معالجة المستندات والتعرف الضوئي (Document & AI OCR):**
- **[PDF.js (Mozilla)](https://mozilla.github.io/pdf.js/):** تحليل وتفكيك بنيات ملفات الـ PDF واستخراج طبقات النصوص والجداول.
- **[PDF-Parse](https://www.npmjs.com/package/pdf-parse):** معالجة نصوص الـ PDF السريعة من جانب الخادم.
- **[Tesseract.js](https://tesseract.projectnaptha.com/):** محرك التعرف الضوئي على الحروف (OCR) لدعم اللغتين العربية والإنجليزية للفواتير الممسوحة ضوئياً.

### **الواجهة الأمامية (Frontend & UI):**
- **HTML5 & Semantic Structure:** هيكلية دلالية متوافقة مع محركات البحث وسهولة الوصول.
- **Vanilla CSS (Pure CSS3):** تصميم Glassmorphism مخصص، وتأثيرات ضوئية محيطية، بدون الاعتماد على أطر عمل ثقيلة.
- **Pure JavaScript (ES6+):** معالجة تفاعلية غير متزامنة، وتحميل دفعي سلس.
- **Inline SVG Icons:** أيقونات خفيفة ونقية لتجربة مستخدم عالية الدقة.

## 🛡️ درع الحماية ضد الحظر (Anti-Ban Shield)

تم تصميم النظام خصيصاً للتوافق مع إرشادات وسياسات خوارزميات الواتساب:

```
[دفعة فواتير مرفوعة] 
       │
       ▼
[استخراج البيانات والتحقق من القائمة المستبعدة (Blacklist)]
       │
       ▼
[محاكاة الكتابة الحية (sendStateTyping)] ──► 1.5 ~ 3 ثواني
       │
       ▼
[إرسال الفاتورة مع نص مخصص (Spintax)]
       │
       ▼
[تأخير عشوائي ذكي (Jitter Delay)] ──► 10 ~ 20 ثانية بين كل رسالة
       │
       ▼
[استراحة تبريد بعد كل دفعة (Batch Cooldown)] ──► 60 ثانية استراحة بعد كل 8 رسائل
       │
       ▼
[فحص الحد اليومي (Daily Quota Guard)]
```

## 🚀 طريقة التثبيت والتشغيل (Installation & Quick Start)

### 1. المتطلبات المسبقة (Prerequisites)
- تثبيت بيئة **[Node.js](https://nodejs.org/)** (الإصدار 18 أو 20 أو أحدث يوصى به).
- متصفح Google Chrome مثبت على الجهاز.
- جهاز هاتف مع تطبيق WhatsApp فعال.

### 2. استنساخ المشروع (Clone Repository)
```bash
git clone https://github.com/omar-bakhsh/whatsapp-invoice-app.git
cd whatsapp-invoice-app
```

### 3. تثبيت الاعتماديات (Install Dependencies)
```bash
npm install
```

### 4. تشغيل الخادم (Start Server)
```bash
npm start
```
*أو للتشغيل في بيئة التطوير مع المراقبة:*
```bash
node server.js
```

### 5. فتح لوحة التحكم
1. افتح المتصفح وتوجه إلى: **`http://localhost:3020`** (أو المنفذ المحدد في الإعدادات).
2. سيظهر لك رمز الاستجابة السريعة (**QR Code**).
3. افتح تطبيق واتساب على هاتفك > **الأجهزة المرتبطة** > **ربط جهاز** > قم بمسح الرمز.
4. بمجرد ظهور شارة **"متصل ومحمي"** باللون الأخضر، يصبح النظام جاهزاً للإرسال!

## 📖 دليل الاستخدام (User Guide)

1. **إرسال مجموعة فواتير (Batch Upload):**
   - اسحب وأفلت مجموعة ملفات PDF أو مجلداً كاملاً في منطقة الرفع.
   - سيقوم النظام بتحليل الفواتير واستخراج أرقام الجوال تلقائياً وعرضها في السجل.
   - انقر على **"بدء الإرسال الآمن للفواتير"**.

2. **الإرسال المباشر / اليدوي (Direct Send):**
   - انتقل إلى تبويب **"إرسال يدوي / فوري"**.
   - أدخل رقم العميل واختر ملف الفاتورة ثم اضغط **"إرسال الفاتورة الآن"**.

3. **تخصيص القوالب ودرع الأمان (Settings):**
   - انتقل إلى تبويب **"القوالب وإعدادات الحماية"**.
   - يمكنك تعديل نص الرسالة، إضافة تنويعات Spintax، تعديل رابط التقييم، وتغيير فترات التأخير والتبريد بما يناسب حجم عملك.

## 🔒 الأمان والخصوصية (Privacy & Security)

- **حفظ محلي كامل (100% Local Execution):** تعمل جميع العمليات ومعالجة الفواتير وجلسات الواتساب محلياً داخل جهازك دون رفع أي بيانات إلى خوادم خارجية طرف ثالث.
- **عزل الجلسات:** يتم حفظ بيانات المصادقة في مجلد مشفر محلياً (`.wwebjs_auth`) وهو مستثنى تماماً من الرفع في نظام Git عبر `.gitignore`.
